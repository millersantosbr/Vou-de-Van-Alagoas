# Política de Segurança

## Versões com Suporte

| Versão | Suportada |
| :--- | :--- |
| `main` (produção em voudevan-al.web.app) | :white_check_mark: |
| Versões anteriores | :x: |

## Como Relatar uma Vulnerabilidade

A segurança e a privacidade dos passageiros e usuários do **Vou de Van Alagoas** são prioridades fundamentais.

Se você encontrou uma vulnerabilidade de segurança:
1. **NÃO** abra uma issue pública detalhando o problema.
2. Utilize o recurso oficial de **Private Vulnerability Reporting** do GitHub na aba `Security` deste repositório, ou entre em contato diretamente pelo perfil do mantenedor [@millersantosbr](https://github.com/millersantosbr).
3. Descreva a falha com detalhes:
   - Passos para reproduzir o problema
   - Tipo de impacto (ex: Cross-Site Scripting, vazamento de configuração, etc.)
   - Sugestão de correção (se houver)

Agradecemos imensamente a comunidade de segurança e pesquisadores independentes pela ajuda contínua em manter o projeto seguro para todos.
